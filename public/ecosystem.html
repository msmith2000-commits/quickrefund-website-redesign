Gateway Integration

Transaction

Consumer makes a purchase. The transaction flows through the merchant's payment gateway—and QuickRefund connects server-to-server at the gateway level.

Hover for details
  • Consumer purchases from merchant storefront
  • Transaction routes through gateway (NMI, Authorize.net, Stripe, etc.)
  • QuickRefund connects server-to-server at the gateway level
  • Transaction data captured: amount, descriptor, card BIN, timestamp
  • No consumer-facing changes—invisible integration

Automated Processing

Refund Execution

Merchant approves (or auto-approves) and QuickRefund executes the refund server-to-server against the original transaction. Clean, auditable, VAMP-safe.

Hover for details

  • Refund executed server-to-server against original transaction ID
